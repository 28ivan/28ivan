## Proyectos destacados

### Ingeniería de Software y Arquitectura
- **[KittyBoom (Bomberman 2D)](https://github.com/28ivan/kittyboom-bomberman):** Juego de escritorio en Java SE 17 diseñado bajo arquitectura MVC estricta y patrones clásicos GoF para desacoplar el ciclo de juego y la vista reactiva. Cuenta con pipeline CI/CD en GitHub Actions.
- **[Pokédex Web MVC](https://github.com/28ivan/pokedex-flask-mvc):** Aplicación web en Flask con persistencia en SQLite, control de acceso por roles (RBAC) y suite de pruebas unitarias.

### Machine Learning y Análisis de Datos
- **[Clustering de Abreviaturas Médicas](https://github.com/28ivan/medical-abbreviation-clustering):** Implementación desde cero del algoritmo DBSCAN aplicado a la desambiguación semántica de términos clínicos mediante representaciones vectoriales TF-IDF, Word2Vec y Transformers.
- **[Sistema de Apoyo a la Decisión (DSS)](https://github.com/28ivan/decision-support-ml):** Pipeline integral de minería de opiniones que combina modelado de tópicos (LDA), clasificación supervisada multimodelo y aumento sintético de datos con LLMs locales (Ollama).

### Integración de Sistemas y APIs Cloud
- **[Plataforma de Streaming Musical](https://github.com/28ivan/music-streaming-flask):** API REST en Flask con seguridad criptográfica de contraseñas, subida y validación de archivos multimedia y cliente web SPA.
- **[eGela2Dropbox](https://github.com/28ivan/web-systems-project):** Cliente de escritorio en Tkinter para automatización de web scraping y sincronización en la nube con la API v2 de Dropbox mediante el protocolo OAuth 2.0.
